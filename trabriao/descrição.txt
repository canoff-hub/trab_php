Trabalho Prático – Desenvolvimento de CRUD em PHP com MySQL
Objetivo
Desenvolver uma aplicação web utilizando PHP procedural e MySQL, implementando operações completas de CRUD (Create, Read, Update, Delete) em duas tabelas relacionadas, utilizando conexão com banco via mysqli_connect (ou mysql_connect, se legado).


Requisitos Técnicos
Linguagem: PHP (sem frameworks)

Banco de Dados: MySQL

Conexão: mysqli_connect

Organização em múltiplos arquivos (mínimo: conexão, listagem, formulário, processamento)
Interface simples em HTML (CSS opcional)
Tabelas e suas funcionalidades
Utilizar dus tabelas uma vinculada a outra (Ex: tabela dono e automoveis, alunos e disciplinas, juizes e processos, usem a criatividade!!!)
Exibir total de valor por pedido (quantidade × preço)
Layout minimamente organizado

Diferenciais ( o aluno deve pesquisar como fazer isso ) 
Implementar busca por nome (criar um form/campo nome)

PARA DUPLAS : CRIAR UM BOTAO DE ORDENACAO ( ordenar a tabela por nome, ou por outro criterio ) 

Implementar uma pesquisa com JOIN, ( criatividade) 

Exibir total de valor por pedido (quantidade × preço) - quando aplicável
Layout minimamente organizado


Critérios de Avaliação
Funcionamento correto do CRUD

Uso adequado de SQL (incluindo JOIN, quando aplicável)

Organização do código

Clareza e legibilidade
