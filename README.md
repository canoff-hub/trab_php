# trab_php
Trabalho que simula um sistema de controle de estoque contendo:
- Botão para adicionar produtos ao estoque que permite definir nome, preço, quantidade e categoria do produto.
- Botão para nomear e criar uma nova categoria de produtos.
- Botão para excluir categorias, sendo necessário o uso de uma senha para excluir qualquer categoria.
- Visualização em tabela dos produtos disponíveis no estoque atualmente, mostrando o ID, nome, categoria,
  preço unitário, quantidade em estoque e subtotal (preço * quantidade).
- A tabela contém, para cada linha, uma aba de ações, que permite editar informações sobre produto (nome, preço,
  etc.) ou excluir do estoque o produto em questão.
  
Ao tentar excluir uma categoria de produtos que contenha qualquer produto, o usuário recebe um aviso alertando
sobre o risco da ação. É necessário marcar uma caixa para confirmar a exclusão de uma categoria com produtos.
O design é leve e segue um estilo simples e moderno, com um tema escuro e cores intuitivas.
